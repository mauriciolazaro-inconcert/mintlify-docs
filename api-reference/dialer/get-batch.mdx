---
title: "Obtener un lote"
description: "Consulta el estado y la configuración de un lote del marcador."
api: "GET https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/{batchId}"
auth: "key"
---

Devuelve la información de un lote concreto, incluidos su estado, métricas, configuración y canal asociado.

## Autenticación

<ParamField header="apikey" type="string" required>
  API key obtenida desde la interfaz de Inagent, dentro del marcador.
</ParamField>

## Parámetros de ruta

<ParamField path="batchId" type="string" required>
  Identificador único del lote.
</ParamField>

## Ejemplo

```bash cURL
curl --request GET \
  --url 'https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/e8b63614-f5db-4fd4-84ab-258b7070262e' \
  --header 'apikey: TU_API_KEY'
```
