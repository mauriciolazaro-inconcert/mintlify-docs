---
title: "Historial de llamadas de un lote"
description: "Consulta los intentos de llamada registrados en un lote."
api: "GET https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/{batchId}/event-history"
auth: "key"
---

Devuelve los intentos de llamada registrados para los contactos de un lote.

<Info>
  En ambas respuestas, cada posición de los arrays de `data` corresponde, en el mismo orden, al nombre incluido en `columns`.
</Info>

## Parámetros

<ParamField header="apikey" type="string" required>
  API key obtenida desde la interfaz de Inagent, dentro del marcador.
</ParamField>

<ParamField path="batchId" type="string" required>
  Identificador único del lote.
</ParamField>

<ParamField query="limit" type="integer">
  Cantidad máxima de registros solicitados.
</ParamField>

<ParamField query="offset" type="integer">
  Desplazamiento desde el primer registro.
</ParamField>

## Ejemplo

```bash cURL
curl --request GET \
  --url 'https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/e8b63614-f5db-4fd4-84ab-258b7070262e/event-history?limit=20&offset=0' \
  --header 'apikey: TU_API_KEY'
```
