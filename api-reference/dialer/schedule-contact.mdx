---
title: "Reagendar un contacto"
description: "Programa un nuevo intento mediante el identificador interno o externo del contacto."
openapi: "api-reference/dialer/openapi.yaml PUT /auto-contact/batches/{batchId}/contacts/schedule/"
---

Reagenda un contacto ya cargado en el lote. En el body debes enviar **exactamente uno** de estos campos:

- `contactId`: identificador interno que genera Inagent al importar el contacto.
- `identifier`: identificador externo definido en el sistema de origen.

El campo `scheduledAt` debe contener una fecha futura en formato ISO 8601 y situada dentro de los próximos 30 días.

<Info>
  `resetAttempts` indica si el contador de intentos debe reiniciarse al aplicar el reagendamiento. La respuesta `200` confirma que la solicitud fue aceptada; el motor de marcación puede tardar en reflejar la nueva fecha.
</Info>

## Ejemplos de body

<CodeGroup>

```json contactId
{
  "contactId": "7d2f8a1b-3c4e-4f50-9a6b-2c3d4e5f6a7b",
  "scheduledAt": "2026-09-19T07:07:17.443Z",
  "resetAttempts": true,
  "reason": "El cliente pidió que lo llamen más tarde"
}
```

```json identifier
{
  "identifier": "CLI-001",
  "scheduledAt": "2026-09-19T07:07:17.443Z",
  "resetAttempts": true,
  "reason": "El cliente pidió que lo llamen más tarde"
}
```

</CodeGroup>

<Warning>
  No envíes `contactId` e `identifier` en la misma petición.
</Warning>
