---
title: "Anular un contacto"
description: "Cierra un contacto para que no vuelva a llamarse en ese lote."
openapi: "api-reference/dialer/openapi.yaml POST /auto-contact/batches/{batchId}/contacts/{contactId}/cancel"
---

La anulación afecta únicamente al contacto dentro del lote indicado. Para excluir una dirección de toda la cuenta, utiliza el endpoint de bloqueo.
