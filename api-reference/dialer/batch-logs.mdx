---
title: "Consultar el log de un lote"
description: "Obtén el registro de cambios y operaciones de un lote del marcador."
api: "GET https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/{batchId}/logs"
auth: "key"
---

Devuelve el registro de operaciones realizadas sobre un lote.

## Autenticación

<ParamField header="apikey" type="string" required>
  API key obtenida desde la interfaz de Inagent, dentro del marcador.
</ParamField>

## Parámetros

<ParamField path="batchId" type="string" required>
  Identificador único del lote.
</ParamField>

<ParamField query="limit" type="integer">
  Cantidad máxima de registros solicitados.
</ParamField>

<ParamField query="offset" type="integer">
  Desplazamiento desde el primer registro.
</ParamField>

## Ejemplo

```bash cURL
curl --request GET \
  --url 'https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/e8b63614-f5db-4fd4-84ab-258b7070262e/logs?limit=50&offset=0' \
  --header 'apikey: TU_API_KEY'
```
