title: "API del marcador"
description: "Autentica y consulta la API del marcador nativo de Inagent."
---

La API del **marcador de Inagent** permite consultar lotes, incorporar contactos, reagendar contactos y revisar el historial operativo y de llamadas.

## URL base

```text
https://api.backend.inconcertcc.com/engine/v1/api/auto-contact
```

## Autenticación

Todos los endpoints de esta sección requieren una API key en el header `apikey`.

```http
apikey: TU_API_KEY
```

Puedes obtener la API key desde la interfaz de Inagent, dentro del marcador.

<Warning>
  Trata la API key como una credencial. No la incluyas en repositorios, código cliente, logs ni ejemplos compartidos.
</Warning>

## Ejemplo autenticado

<CodeGroup>

```bash cURL
curl --request GET \
  --url 'https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches?page=0&size=10' \
  --header 'apikey: TU_API_KEY'
```

```javascript JavaScript
const response = await fetch(
  "https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches?page=0&size=10",
  {
    headers: {
      apikey: process.env.INAGENT_DIALER_API_KEY
    }
  }
);

const data = await response.json();
```

```python Python
import os
import requests

response = requests.get(
    "https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches",
    headers={"apikey": os.environ["INAGENT_DIALER_API_KEY"]},
    params={"page": 0, "size": 10},
    timeout=10,
)
response.raise_for_status()
data = response.json()
```

</CodeGroup>
