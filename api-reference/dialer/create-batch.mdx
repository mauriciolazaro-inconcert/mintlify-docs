---
title: "Crear un lote"
description: "Crea un lote desde la API o a partir de un CSV previamente subido."
openapi: "api-reference/dialer/openapi.yaml POST /batches"
---

La creación se procesa de forma asíncrona. Conserva el `operationId` de la respuesta para consultar el resultado.

Usa `source: "api"` para crear un lote vacío, sin subir un CSV. Puedes incluir `duplicateStrategy` y `rules` en la misma petición para definir la deduplicación y las reglas de marcación desde el inicio.

<Info>
  Después de crear un lote con `source: "api"`, añade los contactos mediante `POST /batches/{batchId}/contacts`.
</Info>
