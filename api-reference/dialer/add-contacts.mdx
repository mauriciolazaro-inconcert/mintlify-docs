---
title: "Insertar contactos en un lote"
description: "Añade uno o varios contactos a un lote existente del marcador."
api: "POST https://api.backend.inconcertcc.com/engine/v1/api/auto-contact/batches/{batchId}/contacts/"
auth: "key"
---

Añade contactos a un lote existente y deja la operación en cola para su procesamiento.

## Autenticación

<ParamField header="apikey" type="string" required>
  API key obtenida desde la interfaz de Inagent, dentro del marcador.
</ParamField>

## Parámetros de ruta

<ParamField path="batchId" type="string" required>
  Identificador único del lote que recibirá los contactos.
</ParamField>

## Body

<ParamField body="contacts" type="array" required>
  Lista de contactos que se incorporarán al lote.
</ParamField>

<ParamField body="contacts[].identifier" type="string" required>
  Identificador del contacto dentro del lote.
</ParamField>

<ParamField body="contacts[].name" type="string">
  Nombre del contacto.
</ParamField>

<ParamField body="contacts[].addresses" type="array" required>
  Direcciones de contacto. Cada elemento contiene `address`, `type` y `priority`.
</ParamField>

<ParamField body="contacts[].contactPriority" type="integer">
  Prioridad asignada al contacto.
</ParamField>

<ParamField body="contacts[].customFields" type="object">
  Campos personalizados asociados al contacto.
</ParamField>
