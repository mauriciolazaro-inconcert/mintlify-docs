---
title: "Historial de llamadas de un contacto"
description: "Consulta los intentos de llamada de un contacto dentro de un lote."
api: "GET https://api.backend.inconcertcc.com/autocontact/api/v1/batches/contacts/{contactId}/event-history"
auth: "key"
---

Devuelve los intentos de llamada de un contacto concreto dentro de un lote.

<Info>
  Cada posición de los arrays de `data` corresponde, en el mismo orden, al nombre incluido en `columns`.
</Info>

## Parámetros

<ParamField header="apikey" type="string" required>
  API key obtenida desde la interfaz de Inagent, dentro del marcador.
</ParamField>

<ParamField path="contactId" type="string" required>
  Identificador interno del contacto devuelto por el historial del lote.
</ParamField>

<ParamField query="batchId" type="string" required>
  Identificador del lote al que pertenece el contacto.
</ParamField>

<ParamField query="limit" type="integer">
  Cantidad máxima de registros solicitados.
</ParamField>

<ParamField query="offset" type="integer">
  Desplazamiento desde el primer registro.
</ParamField>

## Ejemplo

```bash cURL
curl --request GET \
  --url 'https://api.backend.inconcertcc.com/autocontact/api/v1/batches/contacts/01a07b9f-cd7f-772c-adc5-e05f5b20d196/event-history?limit=50&offset=0&batchId=e8b63614-f5db-4fd4-84ab-258b7070262e' \
  --header 'apikey: TU_API_KEY'
```
